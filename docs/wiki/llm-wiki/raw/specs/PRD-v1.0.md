## Alcance curado

Sistema ficticio de agendamiento de citas con actores USER, PROFESSIONAL y ADMIN. El PRD define RF-01 a RF-20: identidad y JWT, perfil/afiliación, catálogos, profesionales, bloques de disponibilidad, slots de 30 minutos, citas generales y especializadas, cancelación, reprogramación, agenda profesional, cierre de atención, bandeja administrativa, auditoría y REST directo entre frontend y backend.

Las reglas RN-01 a RN-12 exigen evitar doble reserva, aprobación automática de cita general, aprobación administrativa de especializada, motivo obligatorio de rechazo, slots consecutivos para 60 minutos, prohibición de pasado, validación de sede/especialidad, liberación de reservas, protección de cita original durante reprogramación y auditoría verificable.

Los detalles operativos se verifican siempre contra el origen canónico. Esta fuente no autoriza inferencias para puntos no especificados.
