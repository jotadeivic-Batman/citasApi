# Esquema de la LLM Wiki

La wiki global mantiene conocimiento durable del workspace de citas. `raw/` conserva fuentes curadas; `wiki/` contiene síntesis verificables. La documentación Scrum vive fuera de esta wiki, en `../../scrum/`.

Los cambios a la estructura, fuentes o conocimiento mantenido deben actualizar `wiki/index.md` y añadir un evento append-only a `wiki/log.md`.

Consultar los documentos de este directorio antes de INGEST, QUERY, LEARN o LINT.
