# Modelo de contenido

Cada afirmación durable mantenida en `wiki/` debe poder rastrearse a una fuente, una verificación de código o una decisión explícita.

| Tipo | Uso | Requisito |
| --- | --- | --- |
| HECHO | Requisito, estado o comportamiento verificable. | Fuente o evidencia identificable. |
| DECISIÓN | Elección aprobada para el proyecto. | Aprobador, fecha y contexto. |
| PREFERENCIA | Convención reversible de trabajo o presentación. | Origen y alcance. |
| PREGUNTA ABIERTA | Ambigüedad que bloquea o condiciona diseño. | No se trata como hecho. |

No convertir una inferencia en HECHO. Las decisiones pendientes se mantienen en `wiki/risks-and-open-questions.md` hasta su aprobación.
