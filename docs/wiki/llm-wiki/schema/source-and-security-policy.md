# Política de fuentes y seguridad

- El PRD aprobado y las restricciones técnicas son las fuentes normativas primarias.
- Una HU aprobada puede concretar alcance, pero no contradecir dichas fuentes.
- Las fuentes RAW no se reescriben; las revisiones se incorporan como una nueva versión.
- No persistir contraseñas, JWT, refresh tokens, OAuth, credenciales de Gmail/n8n/MCP, datos personales reales ni logs que los contengan.
- Las sedes y especialidades públicas incluidas en los requisitos pueden referenciarse solo dentro del contexto académico indicado.
- La solución `database/reference/` requiere autorización explícita del trainer antes de usarla como fuente de comparación o ingestión.
