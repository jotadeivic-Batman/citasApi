# Contexto del proyecto

## HECHOS

- El proyecto es un laboratorio académico para un sistema ficticio de agendamiento de citas.
- El workspace coordina dos repositorios Git independientes: `citas-api` y `citas-web`.
- Los datos de pacientes, profesionales, credenciales, EPS, planes, horarios y citas del laboratorio deben ser sintéticos.
- La única LLM Wiki global se mantiene en `citas-api/docs/wiki/llm-wiki/`.

## Alcance de producto

El alcance funcional se define en el PRD v1.0. Incluye identidad, afiliación, catálogos, agenda profesional, disponibilidad, ciclo de vida de citas y reprogramaciones, auditoría de estados y automatizaciones posteriores.

**Fuentes:** `raw/specs/PRD-v1.0.md`, `raw/governance/evidencias-y-trazabilidad.md`.
